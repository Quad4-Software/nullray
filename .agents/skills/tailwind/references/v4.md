# Tailwind v4 features

## Oxide engine

v4 is a ground-up engine rewrite (Oxide / `@tailwindcss/oxide`). Tailwind
reports large gains on full and incremental builds. Empty incremental rebuilds
(no new classes) finish in microseconds on their Catalyst benchmarks.

## Plugin entrypoints

| Path | Package |
|------|---------|
| Vite | `@tailwindcss/vite` |
| PostCSS | `@tailwindcss/postcss` |
| CLI | `@tailwindcss/cli` |

Common `@theme` prefixes: `--color-*`, `--font-*`, `--spacing-*`,
`--breakpoint-*`, `--ease-*`. Use `@source inline(...)` when class names are
built dynamically.

## CSS-first configuration

Configure design tokens with `@theme` in the CSS file that imports Tailwind.
Custom utilities and variants also move into CSS (`@utility`, and related
directives in the docs).

## Automatic content detection

Template scanning no longer needs a `content` array for typical apps. Heuristics
respect `.gitignore` and skip binary extensions. Add extra roots with:

```css
@import "tailwindcss";
@source "../node_modules/@my-company/ui-lib";
```

## Platform CSS

- Cascade layers for theme / base / components / utilities
- Registered custom properties (`@property`) for gradients and animatable tokens
- `color-mix()` for opacity against any color including CSS variables
- Logical properties for RTL-friendly spacing

## Notable new utilities

- Container queries in core (`@container`, `@sm:`, `@max-*`, stacked ranges)
- 3D transforms (`rotate-x-*`, `translate-z-*`, `perspective-*`, `transform-3d`)
- Expanded gradients (`bg-linear-*`, `bg-conic-*`, `bg-radial-*`, interpolation
  modifiers)
- `starting` variant for `@starting-style`
- `not-*` variant for `:not()` and negated feature queries
- `inset-shadow-*`, `field-sizing`, `color-scheme`, `inert`, `nth-*`, `in-*`

## Dynamic scales

Many spacing and grid utilities accept numeric scales without config
(`grid-cols-15`, `w-17`). Boolean data attributes work as variants without
predeclaring them (`data-current:opacity-100`).
